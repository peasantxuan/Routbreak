# Getting started with Routbreak

## Start with a complete analysis

Routbreak describes the stochastic early phase of an epidemic in
connected communities. The reproduction matrix uses **destination rows
and source columns**: `R[i, j]` is the expected number of infections in
community `i` caused by one infected individual in community `j`.

The following hypothetical three-community system is supercritical and
strongly connected. Copy the complete block into a fresh R session after
installing the package.

``` r

library(Routbreak)

community <- c("North", "Central", "Coast")
R <- matrix(
  c(
    0.95, 0.12, 0.05,
    0.35, 0.85, 0.12,
    0.12, 0.25, 1.05
  ),
  nrow = 3,
  byrow = TRUE,
  dimnames = list(destination = community, source = community)
)

risk <- rob_table(R)
risk
#>   community outbreak_probability     R_ob R_local R_total   R_ref
#> 1     North            0.4495513 1.328039    0.95    1.42 1.25996
#> 2   Central            0.3636076 1.242933    0.85    1.22 1.25996
#> 3     Coast            0.3557093 1.235855    1.05    1.22 1.25996
```

Each row of `risk` answers a question about an introduction into the
named source community:

- `outbreak_probability` is the probability that the branching process
  does not become extinct;
- `R_ob` compares expected offspring conditional on epidemic emergence
  with expected offspring conditional on extinction;
- `R_local` is the diagonal entry of `R`, counting infections that
  remain in the source community;
- `R_total` is the full source-column sum, counting infections generated
  in every destination; and
- `R_ref` is the spectral radius of the complete system and therefore
  has the same value in every row.

The three introduction locations have positive but unequal outbreak
probabilities. `R_local` alone does not rank their epidemic risk because
it ignores where exported infections go. `R_ob` is also not a
community-specific replacement for `R_ref`: it describes
survival-conditioned offspring for a particular introduction location,
whereas `R_ref` characterizes growth of the whole coupled system.

## The four reproduction quantities

The individual functions behind
[`rob_table()`](https://peasantxuan.github.io/Routbreak/reference/rob_table.md)
are useful when only one quantity is needed.

``` r

r_ref(R)    # system-level reference reproduction ratio
#> [1] 1.25996
r_local(R)  # infections that remain within each source community
#>   North Central   Coast 
#>    0.95    0.85    1.05
r_total(R)  # infections generated anywhere by each source community
#>   North Central   Coast 
#>    1.42    1.22    1.22
p <- outbreak_prob(R)
r_ob(R, p)  # supplied p is checked against the maximal fixed point
#>    North  Central    Coast 
#> 1.328039 1.242933 1.235855
```

For Poisson offspring, outbreak probabilities satisfy

``` math
p_i = 1 - \exp\left(-\sum_j R_{ji}p_j\right).
```

Here $`p_i`$ refers to an introduction in source community $`i`$. The
matrix is transposed in the fixed point because `R[j, i]` describes
infections generated by source `i` in destination `j`.

For positive $`p_i`$, the Poisson outbreak reproduction ratio is

``` math
R_i^{ob}=\frac{-\log(1-p_i)}{p_i}
          =\frac{\sum_jR_{ji}p_j}{p_i}.
```

Consequently, $`R_i^{ob}>1`$ whenever $`p_i>0`$. Whether `R_ob` exceeds
one is therefore not, by itself, evidence that a community benefits from
network connections. Compare its magnitude and spatial variation across
introduction locations and with `R_local`, `R_total`, and the common
`R_ref`.

## Change overall transmissibility

[`scale_to_rref()`](https://peasantxuan.github.io/Routbreak/reference/scale_to_rref.md)
changes the system-level reproduction ratio without changing the
relative entries of the matrix.

``` r

targets <- c(0.8, 1.0, 1.2, 1.5, 2.0)
scaled_results <- do.call(rbind, lapply(targets, function(target) {
  scaled <- scale_to_rref(R, target)
  transform(rob_table(scaled), target_R_ref = target)
}))

colors <- c("#0072B2", "#D55E00", "#009E73")
old_par <- par(mfrow = c(1, 2), mar = c(4.2, 4.2, 1.5, 0.8))
plot(
  NA, xlim = range(targets),
  ylim = c(0, max(scaled_results$outbreak_probability)),
  xlab = expression(R[ref]), ylab = "Outbreak probability"
)
for (name in community) {
  selected <- scaled_results$community == name
  lines(
    scaled_results$target_R_ref[selected],
    scaled_results$outbreak_probability[selected],
    type = "o", col = colors[match(name, community)]
  )
}

plot(
  NA, xlim = range(targets), ylim = range(scaled_results$R_ob),
  xlab = expression(R[ref]), ylab = expression(R[ob])
)
for (name in community) {
  selected <- scaled_results$community == name
  lines(
    scaled_results$target_R_ref[selected], scaled_results$R_ob[selected],
    type = "o", col = colors[match(name, community)]
  )
}
legend("topleft", community, col = colors, lty = 1, pch = 1, bty = "n")
```

Below threshold, an irreducible primitive Poisson matrix has zero
outbreak probability and the published continuation sets every `R_ob` to
`R_ref`. Above threshold, introduction locations can separate because
their routes into the surviving process differ.

## Import a long-format matrix

[`as_rmatrix()`](https://peasantxuan.github.io/Routbreak/reference/as_rmatrix.md)
makes orientation explicit when reproduction means are stored as
directed edges.

``` r

edges <- expand.grid(
  destination = community,
  source = community,
  stringsAsFactors = FALSE
)
edges$mean_offspring <- mapply(
  function(destination, source) R[destination, source],
  edges$destination,
  edges$source
)

R_from_long <- as_rmatrix(
  edges,
  source = "source",
  destination = "destination",
  value = "mean_offspring",
  communities = community
)
identical(R_from_long, R)
#> [1] TRUE
```

By default, every directed pair must be present. An explicit row with
value zero creates a zero entry; an absent row is treated as unobserved
and causes an error. Set `missing = "zero"` only when the scientific
data definition makes absence equivalent to zero.

## Check matrix structure

``` r

is_irreducible(R)
#> [1] TRUE
matrix_diagnostics(R)
#>   community component component_size cyclic_period primitive_component
#> 1     North         1              3             1                TRUE
#> 2   Central         1              3             1                TRUE
#> 3     Coast         1              3             1                TRUE
#>   matrix_irreducible
#> 1               TRUE
#> 2               TRUE
#> 3               TRUE
```

The component diagnostic identifies reducible matrices and reports each
strongly connected component’s cyclic period. A period of one is
primitive. Periodicity matters for the generation-limit continuation
below threshold; Routbreak does not replace a non-existent limit for an
imprimitive matrix with an arbitrary cycle average.

## Assumptions and supported cases

The calculation is an early-epidemic, multitype branching-process
approximation with a fixed nonnegative reproduction matrix. Extinction
means that the transmission chain eventually ends. Outbreak probability
is not the final attack rate and does not describe epidemic size after
emergence.

Poisson
[`r_ob()`](https://peasantxuan.github.io/Routbreak/reference/r_ob.md)
supports supercritical irreducible systems, primitive irreducible
systems at or below threshold through the published continuation, and
diagonal matrices as independent communities. General reducible
non-diagonal matrices and periodic continuation cases are reported
rather than assigned an invented value. The advanced [overdispersion
tutorial](https://peasantxuan.github.io/Routbreak/articles/negative-binomial.md)
covers independent-edge negative-binomial offspring; the [inference
tutorial](https://peasantxuan.github.io/Routbreak/articles/estimating-rob.md)
covers estimation from directed transmission data.

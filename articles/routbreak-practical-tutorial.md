# Routbreak: A practical tutorial on outbreak risk in connected populations

## 1. Introduction and installation

### What does Routbreak calculate?

Routbreak describes early epidemic emergence when population groups are
connected. Given a reproduction matrix, it calculates:

- the probability that an introduction produces a non-extinct
  transmission chain;
- the introduction-specific outbreak reproduction ratio, `R_ob`;
- local and total reproduction for each group; and
- the system-level reference reproduction ratio, `R_ref`.

Throughout Routbreak, **rows are infection destinations and columns are
infection sources**. Thus `R[i, j]` is the expected number of infections
in destination group `i` produced by one infected individual from source
group `j`.

Routbreak is not yet available from CRAN. Install it from GitHub with:

``` r

install.packages("remotes")
remotes::install_github("peasantxuan/Routbreak")
```

The survey-data example later in this tutorial uses `socialmixr`, a
suggested package available from CRAN. Its bundled POLYMOD survey lets
the example run offline; Routbreak does not download or redistribute
those records.

## 2. A minimal reproduction matrix

### How is a connected population represented?

Consider three hypothetical communities. The names on both dimensions
make the matrix convention explicit.

``` r

library(Routbreak)

community <- c("North", "Central", "Coast")

R <- matrix(
  c(
    0.95, 0.12, 0.05,
    0.35, 0.85, 0.12,
    0.12, 0.25, 1.05
  ),
  nrow = 3,
  byrow = TRUE,
  dimnames = list(destination = community, source = community)
)
R
#>            source
#> destination North Central Coast
#>     North    0.95    0.12  0.05
#>     Central  0.35    0.85  0.12
#>     Coast    0.12    0.25  1.05
```

Column `"North"` contains infections generated by a source case in
North. Row `"North"` contains infections arriving in North from all
three sources. For example, `R["Central", "North"]` is the expected
number of Central infections generated by one North source case.

``` r

R[, "North"]
R["North", ]

stopifnot(
  identical(rownames(R), colnames(R)),
  all(is.finite(R)),
  all(R >= 0)
)
```

## 3. Basic Routbreak metrics

### What does one introduction imply for each community?

[`rob_table()`](https://peasantxuan.github.io/Routbreak/reference/rob_table.md)
calculates the main quantities together, reusing the outbreak
probabilities internally.

``` r

risk <- rob_table(R)
risk
#>   community outbreak_probability     R_ob R_local R_total   R_ref
#> 1     North            0.4495513 1.328039    0.95    1.42 1.25996
#> 2   Central            0.3636076 1.242933    0.85    1.22 1.25996
#> 3     Coast            0.3557093 1.235855    1.05    1.22 1.25996
```

Each row corresponds to the source community where infection is
introduced:

- `outbreak_probability` is the probability that the early branching
  process does not eventually become extinct. It is not the final
  epidemic size.
- `R_ob` contrasts offspring production conditional on emergence with
  offspring production conditional on extinction.
- `R_local` is the diagonal entry of `R`, counting infections that
  remain in the source community.
- `R_total` is the source-column sum, counting infections generated
  across all destinations.
- `R_ref` is the spectral radius of the complete connected system. It is
  repeated in each row only to simplify comparison.

The same quantities are available separately through
[`outbreak_prob()`](https://peasantxuan.github.io/Routbreak/reference/outbreak_prob.md),
[`r_ob()`](https://peasantxuan.github.io/Routbreak/reference/r_ob.md),
[`r_local()`](https://peasantxuan.github.io/Routbreak/reference/r_local.md),
[`r_total()`](https://peasantxuan.github.io/Routbreak/reference/r_total.md),
and
[`r_ref()`](https://peasantxuan.github.io/Routbreak/reference/r_ref.md)
when only one output is needed.

The introduction locations share one system-level `R_ref`, but their
outbreak probabilities and `R_ob` values differ because they enter
different parts of the connected transmission system. `R_local` alone
misses exported transmission, while `R_total` does not account for the
future paths reached by those exported infections.

## 5. Survey-data example: age-structured contacts in Italy

### How is the Italian contact matrix constructed?

The POLYMOD study recorded one day of contacts for participants in eight
European countries during 2005–2006. The `socialmixr` CRAN package
includes version 1.1 of these survey records. Its Italian subset has 849
participant records. With the explicit missing-age handling below, 842
participants contribute to the contact matrix. Participant and contact
ages are grouped into 5-year bands from 0–4 through 75–79, plus an 80+
group.

[`socialmixr::contact_matrix()`](https://epiforecasts.io/socialmixr/reference/contact_matrix.html)
returns the mean number of contacts reported by each participant age
group in **rows**, with contacted age groups in **columns**. Thus its
matrix has source rows and destination columns. The call below uses the
observed Italian survey participants within each age band. It does not
apply an external national population distribution, age weights, or a
reciprocity adjustment; the 17 analytic group counts range from 5 to 93
participants.

``` r

data("polymod", package = "socialmixr")

italy_contacts <- socialmixr::contact_matrix(
  survey = polymod,
  countries = "Italy",
  age_limits = seq(0, 80, by = 5),
  symmetric = FALSE,
  estimated_participant_age = "mean",
  estimated_contact_age = "mean",
  missing_participant_age = "remove",
  missing_contact_age = "remove"
)

C_italy <- italy_contacts$matrix
age_group <- c(paste(seq(0, 75, 5), seq(4, 79, 5), sep = "-"), "80+")
dimnames(C_italy) <- list(source = age_group, destination = age_group)

survey_basis <- italy_contacts$participants
available_Italian_participants <- sum(
  as.character(polymod$participants$country) == "Italy"
)
data.frame(
  available_Italian_participants,
  participants_in_contact_matrix = sum(survey_basis$participants),
  minimum_per_age_group = min(survey_basis$participants),
  maximum_per_age_group = max(survey_basis$participants)
)
#>   available_Italian_participants participants_in_contact_matrix minimum_per_age_group
#> 1                            849                            842                     5
#>   maximum_per_age_group
#> 1                    93
```

### How is the contact matrix converted to a reproduction matrix?

For this teaching scenario, every reported contact is assigned the same
expected transmission multiplier $`\beta`$. Susceptibility,
infectiousness, and infectious-period scaling are therefore uniform
across age groups. If $`C_{sj}`$ is the mean number of contacts that a
participant in source group $`s`$ reports with destination group $`j`$,
then

``` math
R_{js}=\beta C_{sj}.
```

The transpose below is required only to convert the documented
`socialmixr` orientation to Routbreak’s destination-row/source-column
convention. Scaling sets the illustrative system-level value to
`R_ref = 1.5`; this value is not an empirical estimate for Italy.

``` r

A_italy <- t(C_italy)
dimnames(A_italy) <- list(destination = age_group, source = age_group)
R_italy <- scale_to_rref(A_italy, target = 1.5)

result_italy <- rob_table(R_italy)
print(result_italy, digits = 4)
#>    community outbreak_probability  R_ob R_local R_total R_ref
```

Each entry of `R_italy` is the expected number of infections in a
destination age group generated by an infected source age group under
this uniform per-contact scenario. Routbreak calculates outbreak
probability, `R_ob`, `R_local`, `R_total`, and the common `R_ref` for
each introduction group.

### Does the generated matrix pass the required checks?

``` r

diagnostics_italy <- matrix_diagnostics(R_italy)

r_ref(R_italy)
#> [1] 1.5
is_irreducible(R_italy)
#> [1] TRUE
unique(diagnostics_italy[c(
  "component_size", "cyclic_period", "primitive_component",
  "matrix_irreducible"
)])
#>   component_size cyclic_period primitive_component matrix_irreducible
#> 1             17             1                TRUE               TRUE

italy_metrics <- c("outbreak_probability", "R_ob", "R_local", "R_total")
italy_summary <- t(vapply(
  result_italy[italy_metrics],
  function(x) c(minimum = min(x), maximum = max(x), sd = sd(x)),
  numeric(3)
))
italy_summary
#>                         minimum  maximum        sd
#> outbreak_probability 0.20278461 0.701367 0.1364766
#> R_ob                 1.11759164 1.723120 0.1607619
#> R_local              0.01386387 1.215069 0.3460406
#> R_total              0.56841873 1.976592 0.3874185

italy_spearman <- cor(
  result_italy[italy_metrics],
  method = "spearman"
)
round(italy_spearman, 3)
#>                      outbreak_probability  R_ob R_local R_total
#> outbreak_probability                1.000 1.000   0.777   0.985
#> R_ob                                1.000 1.000   0.777   0.985
#> R_local                             0.777 0.777   1.000   0.801
#> R_total                             0.985 0.985   0.801   1.000
```

The generated matrix is irreducible and primitive, with spectral radius
1.5.
[`r_ref()`](https://peasantxuan.github.io/Routbreak/reference/r_ref.md)
confirms the requested system-level normalization;
[`is_irreducible()`](https://peasantxuan.github.io/Routbreak/reference/is_irreducible.md)
confirms that every age group can reach every other through positive
transmission paths.
[`matrix_diagnostics()`](https://peasantxuan.github.io/Routbreak/reference/matrix_diagnostics.md)
additionally reports one strongly connected component with cyclic period
1, so the matrix is primitive. It produces genuine age-type variation:
outbreak probability ranges from 0.203 to 0.701, `R_ob` from 1.118 to
1.723, `R_local` from 0.014 to 1.215, and `R_total` from 0.568 to 1.977.
These rounded values are calculated by the preceding code when the
optional package is available.

For these 17 groups, Spearman’s rank correlation is 0.985 between
outbreak probability and `R_total`, and 0.777 between outbreak
probability and `R_local`. Outbreak probability and Poisson `R_ob` have
rank correlation 1 because `R_ob = -log(1-p)/p` is strictly increasing
for positive $`p`$. `R_ref` is constant and therefore has no defined
rank correlation with the age-specific metrics.

`R_local` counts infections that remain within the source age group.
`R_ob` uses the entire age-connected system and conditions on whether
transmission survives. The common `R_ref` remains a property of the full
17-group matrix.

**Assumptions.** This example uses an unsymmetrized mean contact matrix
from the Italian POLYMOD survey sample and a Poisson multitype branching
process. It assumes a common transmission contribution per reported
contact and uniform susceptibility, infectiousness, and duration
scaling. It does not adjust the survey to a national age distribution.
The calculations describe early non-extinction under this illustrative
model; they do not estimate final epidemic size or establish empirical
age-specific risks for a pathogen or time period.

## 6. Use your own matrix

### What information must a matrix provide?

Supply a finite, nonnegative square matrix with the same unique
community identifiers on its destination rows and source columns. Record
the time scale, population definitions, and scientific process used to
construct every entry.

``` r

my_R <- matrix(
  c(1.1, 0.2, 0.1, 0.9),
  nrow = 2,
  byrow = TRUE,
  dimnames = list(
    destination = c("Group A", "Group B"),
    source = c("Group A", "Group B")
  )
)

rob_table(my_R)
#>   community outbreak_probability     R_ob R_local R_total    R_ref
#> 1   Group A            0.2915450 1.182215     1.1     1.2 1.173205
#> 2   Group B            0.2396923 1.143266     0.9     1.1 1.173205
```

For long-format data,
[`as_rmatrix()`](https://peasantxuan.github.io/Routbreak/reference/as_rmatrix.md)
requires explicit column names and does not interpret missing edges as
zero unless requested.

``` r

edges <- data.frame(
  source = c("A", "A", "B", "B"),
  destination = c("A", "B", "A", "B"),
  expected_infections = c(1.1, 0.1, 0.2, 0.9)
)

as_rmatrix(
  edges,
  source = "source",
  destination = "destination",
  value = "expected_infections"
)
#>            source
#> destination   A   B
#>           A 1.1 0.2
#>           B 0.1 0.9
```

Generation-resolved transmission data require a different workflow. See
[Estimating outbreak reproduction ratios from early transmission
data](https://peasantxuan.github.io/Routbreak/articles/estimating-rob.md)
for explicit priors, previous-generation exposure indexing, and
posterior credible intervals.
